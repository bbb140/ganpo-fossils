# 赣鄱石语 · 江西古生物化石产地科普站

把《江西省古生物化石保护规划（2016—2025 年）》的四大保护分区，做成一张能点开、能检索的分布图。

**线上地址**：https://\<用户名\>.github.io/ganpo-fossils/ （首次部署后填这里）

## 页面

| 页面 | 内容 |
|---|---|
| `index.html` | 数据速览、四大保护分区（条数/小区构成/产地表/门类），全部由数据渲染 |
| `map.html` | 天地图底图 + 109 处产地，按保护级别配色（世界级5/国家级17/省级87），支持关键词与四组筛选，点开右侧详情 |
| `list.html` | 名录表格，可排序、可筛选、可导出 CSV，点行跳地图定位 |
| `download.html` | 数据下载（CSV + GeoJSON）、17 个字段说明、引用格式、使用限制 |
| `atlas.html` | 化石图鉴探索：四区闯关、产地知识小考、盲盒猜物种、发现化石收入图鉴、集齐徽章。导航第五项进入 |

### 化石图鉴探索（`atlas.html`）

- **答辩友好**：全新访客首次打开**默认开启演示模式**（全解锁 + 跳过答题 + 全图鉴预览），老师点进来不会被第一关卡住；页面顶部开关可关掉进入正常闯关，关掉后还原到原来的进度（不会锁死在解锁态）。
- **正常玩法**：从赣西北出发，点开产地 → 先读信息卡 → 答对上面的题才算勘探成功；每区通过若干产地解锁下一区，藏化石的产地额外掉落图鉴卡，集齐自动授徽章。
- **徽章墙（10 枚）**：初探者、化石发现者、寻珍者、走遍赣鄱四枚基础徽章；图鉴扩容后新增「无脊椎收藏家」（收 10 条古无脊椎）、「龙裔传人」（集齐全部可探索恐龙类）、「穿越时空」（古生/中生/新生代各收 1 条）、「四方藏家」（四大区各收 1 条）、「半壁江山」（收可探索图鉴一半）、「赣鄱化石大师」（集齐全部）。条件全部按已收集化石回查 `species.json` 判定，不写死条数——以后加化石自动跟随。徽章墙为**六边形勋章卡片**：每枚配一枚中性图案（🔍🦴💎🗺️🐚🦕⏳🧭📚🏆），获得时金铜色立体、未获得时银灰去色；图标写在 `atlas-logic.js` 的 `icon` 字段，全部内联 emoji，离线可用。
- **门槛强度**三档（轻松/标准/挑战）可切，切档不清进度；进度存浏览器 localStorage，刷新不丢。
- **🎲 盲盒猜物种**（顶部入口）：独立趣味玩法，读一段真实鉴定特征、四选一猜化石名，一轮 5 题，可「再给一条线索」降级、答完展示原文出处与文献、成绩存本地最高分。与闯关进度完全隔离，不参与解锁/徽章。
- **数据驱动**：题库从 `sites.json` 真实字段生成，图鉴读 `species.json`，不编造题目或编号；盲盒线索逐字摘自图鉴 `features` 原文（词源解释句自动剔除以免泄露答案），干扰项取真实物种名且同类群优先。以后 B 岗加化石后，跑一句 `python tools/build_atlas_data.py` 重建 `atlas-demo-data.js` 再刷新即可，无需改页面代码。
- 旧原型已归档到 `data/prototype.backup/`，不进 dist、不上线。

## 数据更新（A 岗回传新表后）

```bash
python tools/build_data.py --src 新表.xlsx          # 先看差异，不覆盖
python tools/build_data.py --src 新表.xlsx --apply  # 确认后替换（自动备份到 data/backup/）
python tools/validate_data.py                       # 6 组校验，0 错误才算过
python tools/build_geojson.py                       # 从 sites.json 重生成 sites.geojson
python tools/build_offline.py --dist                # 重建 dist 与离线包
```

`validate_data.py` 同时是**字段契约**：A 岗改列名会直接报错，不会静默变空。

### 物种图鉴接入（现 162 条）

`data/species.json` 现为 **162 条**，由两批数据合并去重而来：

- **152 条**：B 岗《江西省古生物化石图册》系统物种（`species(3).json`），主要为古无脊椎动物（134）
  与古脊椎动物（18）。其中 **44 条有 `tapho_link`**，与《产地对应报告》44 条明细逐条一致
  （31 条强地名锚点 + 13 条市县/年代/地层锚点），编号全部能对上现有 109 处产地。
- **10 条**：早期整理的明星化石（恐龙/恐龙蛋/哺乳类/笔石），新数据未收录，予以保留。
- **4 条同名**（江西南康龙、赣州江西龙、赣州华南龙、丁氏阶齿兽）保留早期的事实核查详版。
- 合并后：**55 条有有效编号、107 条无编号**。无编号者标「产地：某区（具体不详）」，不显示地图定位链接。
  斑嵴龙（*Banji long*）正模为匿名捐赠、无工地可对，`tapho_link` 留空；早期仅它一条无编号时，
  曾在首页分区/大区筛选按大区显示，现无编号条目增多，该猜测回退已收紧（仅 ≤2 条无编号时启用），
  大数据量下改按真实化石门类关联，不凭空给每个分区挂几十条"具体不详"卡片。

**数据契约**：无关联统一用空字符串 `""`（早期）表示，不再用 `"无"`；`build_atlas_data.py`
与前端 `species.js` 均按空值判断。`产地对应报告.json` 的 `species_index` 为旧排序、与现文件序号错位，
但物种名与 `site_id` 均正确，关联以 `species.json` 自带 `tapho_link` 为准，不按序号回填。

无图鉴匹配的分区/筛选自动按「门类」聚合兜底；页面不推测编号、不编造关联。

字段契约见 `js/species.js` 顶部注释：
`genus/species/author_year/cn_name/age/region/taxa/classification/features/reference/tapho_link`
（中文字段名也识别）。新图鉴写入数组后刷新即显示，无需改 JS；再跑一次
`python tools/build_offline.py --dist` 让离线版内联即可。

图鉴靠 `tapho_link`（产地编号，对应 sites.json 的 `id`）与产地关联，可点「地图定位」跳到该点；
未填编号时按 `taxa` 门类做宽松匹配——**注意 taxa 用词必须与产地表 `fossil_group` 一致**，否则匹配落空。

## 部署

推送到 main 后由 `.github/workflows/pages.yml` 自动构建发布，构建前先跑数据校验，有错误就不发。

```bash
bash tools/deploy.sh <GitHub用户名>       # 首次：设 remote 并推送
git push                                  # 之后：改完推就行
```

首次部署需在仓库 Settings → Pages → Source 选 **GitHub Actions**。

## 数据口径（对外必须一致的三句话）

1. **收录全部 109 处产地档案**，据《江西省古生物化石图册》名录逐条重建，覆盖 12 个保护小区，逐条信息可溯源（图册表号 + 规划条款 + 归并依据）。
2. **所有坐标为行政驻地或地名占位，非实测点位**（村级 2–5 / 乡级 5–10 / 县级 20–30 / 市级 60–100 / 地名级PBDB 20–30 km），不得作为实测坐标引用。图上用半透明虚线点区分，实测点升级后自动变实心。
3. **逐条保护级别据图册名录判定：世界级 5 / 国家级 17 / 省级 87**；规划正文口径为 5/20/84，两者略有出入，属两套统计口径。赋存地层图册未提供者 98 条标「无」，待文献补充。
